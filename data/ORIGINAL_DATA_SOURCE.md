# Original RWTH data source

The original measurement waveforms are **not redistributed** in this repository.

RWTH Publications: https://doi.org/10.18154/RWTH-2021-04545

The source dataset is managed by RWTH Aachen University. Read the source record, license, and usage conditions before downloading.

The CSV files in `data/` and `results/` are retained processed research outputs, **not the 5 GB raw instrument archive**.

For the default preprocessing path, extract the provider archive so that `workspace/Rohdaten/` contains the original measurement ZIP files in their provider directory structure. Keep the raw archive outside the published repository.
